## What this is

The factory 221122 display firmware with its matching UICR file. Data outside
the firmware regions is cleared; the factory firmware is unchanged. Use it to
return a display running the unlocked 221122 firmware to stock.

## Installation

1. Back up your display's current firmware first.
2. Download this firmware package.
3. Follow the [display guide](/display) and select this package in the Restore step.

## Compatibility

For Diamond displays running NRF version 221122, including the unlocked release
based on that version.
